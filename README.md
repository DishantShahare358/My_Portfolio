# Dishant Shahare Portfolio

Next.js HUD-style portfolio for Dishant Ganesh Shahare, built in the spirit of an OS/recruiter lab: case studies, skills universe, CLI, and a grounded copilot.

## Run locally

Drive `C:` on this machine was full during setup, so install with caches on `D:` if npm fails with `ENOSPC`:

```powershell
cd D:\Dishant\portfolio
$env:npm_config_cache = "D:\npm-cache"
$env:TEMP = "D:\tmp"
$env:TMP = "D:\tmp"
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
